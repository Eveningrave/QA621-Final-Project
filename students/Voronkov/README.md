#  Консольный интернет-магазин

Полноценное консольное приложение для управления каталогом товаров, корзиной, промокодами и заказами. Реализовано на Python с использованием объектно-ориентированного подхода и паттернов проектирования.

##  Возможности

- **Каталог товаров**: поддержка трёх типов товаров:
  -  Штучные (`PieceProduct`) — кружки, футболки и т.д.
  -  Весовые (`WeightProduct`) — чай, кофе (продажа в килограммах).
  -  Цифровые (`DigitalProduct`) — курсы, электронные книги (без ограничения по складу).
- **Корзина**: добавление, удаление, изменение количества, расчёт стоимости.
- **Промокоды и скидки**:
  - Процентная скидка на всю корзину.
  - Фиксированная скидка от суммы.
  - Акция «3 по цене 2» для выбранной категории.
  - Процентная скидка на определённую категорию товаров.
- **Заказы**: оформление заказа, история заказов, отмена заказа с возвратом товаров на склад.
- **Персистентность**: все данные (каталог, корзина, заказы, промокоды) сохраняются в JSON-файлы и переживают перезапуск приложения.
- **Красивый интерфейс**: использование библиотеки `rich` для вывода таблиц, панелей и цветного текста в терминале.
